# CurseForge project notes — Create: Resonance 1.0.0

## Project title
Create: Resonance

## Short description
Kinetic music for Create: multi-instrument MIDI music boxes (solo or ensemble) and online resonance discs.

## Full description (EN draft)

**Create: Resonance** is a Create addon for NeoForge 1.21.1.

**MIDI** — Imprint blank scores on the MIDI Table, play on Kinetic Music Boxes (solo or section). A Music Conductor syncs matching section boxes by frequency. Tempo follows RPM (~64 = 1.0×). Optional GM SoundFont (`.sf2`) in `config/create_resonance/soundfonts/`.

**Resonance discs** — Craft discs, imprint URLs on the Resonance Press, play on Kinetic Network Jukeboxes (streaming via optional ffmpeg/yt-dlp).

This is an **unofficial MIT-derived** work based on Create: Harmonics by Leonardo Importuna (mochibit). It is **not affiliated** with upstream. Upstream All-Rights-Reserved artwork is **not** included.

Requires: Create 6, Kotlin for NeoForge.
